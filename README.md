# わくわくミニゲーム

スマートフォン向けの子ども用ゲーム集。ホームの2列のカードから7種類のゲームを選べます。従来の4ゲームは「かんたん」「むずかしい」を選択します。新しい記憶・太鼓・しりとりの3ゲームは、練習できる「あそびかた」から「スタート」を押し、少しずつ難しくなる10問で遊びます。「ピカッとひとふで」では電池からドラッグして、通行可能なすべてのマスを一度ずつ通るとクリア。電池以外の通行可能マスはすべて電球で、通ると点灯します。障害物・再訪・斜めは禁止。指を離すと残りのマスを通れるか判定します。解答があれば線の先端から再開でき、解答不可能と確定した場合は「まちがえちゃった！」と「もういちど」を表示します。「もういちど」は同じ問題を最初からやり直します。全マスを通った場合も、指を離した時に「できた！」を表示します。

問題は毎回自動生成します。リセットは同じ問題を最初からやり直し、クリア後の「つぎへ」は同じ難易度の新しい問題を生成します。従来4ゲームとも「かんたん」「むずかしい」それぞれ10問を1セットにします。一筆書き・ブロックぴったり・レールつなぎは、1〜5問で小さい盤面、6〜10問で大きい盤面になります（かんたん3×3→4×4、むずかしい4×4→5×5）。セットの途中で盤面サイズが小さく戻ることはありません。キューブぴったりは従来どおり各難易度の立体サイズを維持します。10問目をクリアすると「ぜんぶ できた！」の終了画面になり、「もう10もん あそぶ」で同じ難易度の新しい10問を始められます。「ホームにもどる」でゲーム選択へ戻れます。問題そのものは自動生成のため、何セットでも遊べます。ゲームを開き直すと新しい1問目から始まります。

- かんたん: 3×3→4×4、障害物1～3マス。角から始まり、直進を優先した短めの経路です。
- むずかしい: 4×4→5×5、障害物3～6マス。盤面の内側からの開始を基本に、分岐のある形を作ります。

先に重複のない上下左右の経路を作り、その外側を障害物にします。生成後に経路・電球・障害物の整合性を検証します。試行回数に上限を設け、経路が作れない場合も解ける折り返し経路に切り替えます。

判定は最大5×5に対応し、残りのマスのつながり・行き止まりによる枝刈りとメモ化を使います。生成時の解答との一致は要求せず、別解も認めます。ドラッグ中は探索せず、指を離した時だけ最大8ms・10,000探索状態を目安に調べ、上限で結論が出ない場合は失敗にせず続行できます。キーボードでは矢印キーを離した時に判定します。

「ブロックぴったり」は、カラフルな連結ブロックを指でドラッグして盤面にはめるパズルです。回転・落下・制限時間・スコアはありません。

- かんたん: 3×3→4×4、2～3個の大きな長方形中心のピース。
- むずかしい: 4×4→5×5、4～5個。L字・T字・階段形などを含み、少し試行錯誤する形。

完成した四角い盤面を分割し、ピースの連結を保ちながら境界を変えてから順番をシャッフルします。生成後に全マスの被覆・重なり・連結を検証し、生成がうまくいかない場合は安全な問題を使います。生成時と異なる配置でも、全ピースで盤面を隙間なく埋めればクリアです。

置ける場所で離すとマスに吸着し、重なりや盤面外なら元へ戻ります。配置済みのピースも動かせて、下のブロック置き場へ戻せます。リセットは問題・形・順番を維持し、「つぎへ」は同じ難易度で再生成します。タッチ中はページをスクロールせず、ドラッグ中のピースを少し上に表示します。

全4ゲームは難易度を選んで入ると最初に「あそびかた」が表示され、「あそぶ！」で開始します。プレイ中も「？」ボタンからいつでも説明を見返せます。説明は各ゲームの開始時のみで、同じ10問セットの途中には出ません。

「レールつなぎ」は、黄色い枠・回転マークのある一部のレールだけをタップして90度ずつ回し、はじまりの駅からゴールへ電車を走らせるパズルです。その他のレールは正しい向きに固定され、道筋のヒントになります。かんたんは2〜3枚、むずかしいは3〜4枚のみ回せます。駅の位置と接続方向は固定です。

- かんたん: 3×3→4×4、経路5～7マス、カーブ1個、ダミー0～1個。
- むずかしい: 4×4→5×5、経路10～14マス、カーブ4個以上、ダミーあり。

先に重複のない解答経路を作り、直線・カーブのレールにしてから向きを崩します。生成後に接続を検証し、うまく生成できなければ安全な問題を使います。駅に接する2枚のレールを必ず回す必要があり、初期状態で完成した問題は出しません。

接続口のデータで実際の経路をたどるため、別の有効な経路でもクリアでき、使わないダミーの向きは問いません。線路がつながると操作を止め、電車がカーブを含む経路を数秒で走って、駅への到着後に成功画面と進捗を更新します。やりなおしは同じ配置・初期方向へ戻し、問題番号・進捗を維持します。画面移動とやりなおしでは電車のアニメーションを取り消します。

「キューブぴったり」は、欠けた立方体に合うブロックを3択からタップする立体パズルです。候補は表示された向きのまま使い、回転しません。不正解でも同じ問題で何度でも考えられ、正解は穴へ移動して立方体を完成させます。

- かんたん: 3×3×3、欠けるキューブ2～5個。従来のかんたん・むずかしい相当の形を含みます。
- むずかしい: 4×4×4、欠けるキューブ4～5個。大きな立方体の角や辺の段差・奥行きを見分けます。

かんたんは3×3×3、むずかしいは4×4×4で、どちらもスマホ画面に収まるSVGです。3D占有座標から、共有面を除去し、奥から手前へSVGの面を描くアイソメトリック方式です。欠損は外側の見える角から生成し、各ボクセルが見え、残りが連結し、上から差し込めることを検証します。候補も全ボクセルが見える形だけを使い、平行移動で合う正解を1つにします。回転で一致する候補や、投影した面の形・向きが似すぎる候補も除外します。生成は24試行までで、有効な角の問題へフォールバックします。

正解の移動では候補の形と向きを保ち、穴の座標へ表示を合わせてから全占有セルを再描画します。やりなおしは問題・候補順・番号・進捗を維持し、アニメーションを取り消します。動きを減らす設定では演出を短縮します。3つのボタンはキーボードで選べ、番号・個数・形の説明も付いています。

HTML / CSS / JavaScriptのみ。npm・Node.js・ビルド・外部画像・CDN・バックエンドは不要です。ホームの丸文字はZen Maru Gothicを軽量化・改名したローカルWOFFで、OFLライセンスを `assets/fonts/OFL.txt` に同梱しています。SVGイラストは本アプリ用のオリジナルです。

## 新しい3ゲーム

どれも10問・時間切れの失敗なし。不正解でも同じ問題で何度でも試せます。最初の説明画面には、本番に数えない操作練習があります。「やりなおし」は問題を変えずに状態だけを戻し、10問終了後の「もういちどあそぶ」で新しいセットを始めます。

| ゲーム | 1〜3問 | 4〜6問 | 7〜8問 | 9〜10問 |
| --- | --- | --- | --- | --- |
| なにがきえた？ | 3枚・2択 | 4枚・3択 | 5枚・3択 | 6枚・4択 |
| えでしりとり | 2択・1つつなぐ | 3択・1つつなぐ | 同じ種類の絵を含む3択 | 4択・2つつなぐ |

- **なにがきえた？**：絵を5〜8秒覚え、隠した後に消えた1枚を選びます。絵の位置は変わりません。「もういちどみる」で同じ並びを再確認できます。
- **たいこまねっこ**：お手本の光と音を見聞きし、同じ順番にタップします。1〜2問は2音／2種類、3〜4問は3音／2種類、5〜6問は4音／3種類、7〜8問は5音、9〜10問は6音です。赤のまる・青のさんかく・黄色のほしで識別します。太鼓は3台並び、前半では使わない黄色を薄く表示します。「もういちどきく」で再生できます。
- **えでしりとり**：絵と名前を見て、最後の文字から始まる絵を選びます。つながった絵は矢印で残ります。濁点・半濁点はそのまま比較し、「ご」と「こ」、「ぱ」と「は」は別の音です。「ん」で終わる語は問題データに入れません。幼児に難しい小さい文字・長音を避け、身近な「らっぱ」の促音のみ使います。

太鼓の音はユーザーがボタンを押した後にWeb Audioで作ります。音を消しても光で遊べます。音が使えない環境でも入力やクリア判定は変わりません。画面を離れると音・タイマーを止め、戻ったら「つづける」で同じ問題を最初から再開します。プレイ状態を端末へ保存する機能はないため、ページを開き直すと1問目からです。

### 絵・言葉・問題データの追加

`games/common/pictures.js` が絵のID・読み・分類を管理します。`assets/pictures/<ID>.svg` に同じ名前の独自イラストを置き、一覧へ登録してください。記憶ゲームのみの絵は `memory` の追加一覧に入れます。しりとりの絵は `entries` に入れ、最後の文字から続く語（後半では2語分）が存在するようにします。読みはひらがなで、絵と一致させます。

各 `generator.js` の `config(number)` が段階的な難易度を管理します。しりとりは各段階で正解候補を1つ選び、同じ頭文字の別候補を除外します。生成は登録語数と最大2段の範囲で終了します。データ変更後は `node tests/run-logic.cjs` を実行し、正解一意性・しりとりの成立・難易度の単調性を確認してください。絵を追加した場合はPWAの `FILES` への登録とバージョン更新も必要です。

## ローカル起動

ZIPを展開し、`index.html`があるフォルダで:

```sh
python3 -m http.server 8000
```

PCで `http://localhost:8000/` を開きます。`http://localhost:8000/index%20%282%29.html` で合計51項目の検証（一筆書きは各5000問、他3ゲームは各1000問、合計16000問を含む）を実行できます。Pythonは確認用サーバーだけに使います。

検証用のNode.js 18以降があれば、外部ライブラリなしで従来51項目・16,000問と新作各10,000問（合計30,000問）のルール検証を実行できます。

```sh
node tests/run-logic.cjs
```

既にPlaywrightとChromiumがある環境では、サーバー起動後に次のブラウザ試験も実行できます。アプリへの依存追加やnpmの実行は不要です。`CHROMIUM_PATH` でブラウザのパス、`ARTIFACT_DIR` でキューブ試験の画像・計測値の保存先を指定できます。

```sh
node tests/home-browser.cjs http://localhost:8000/
node tests/cube-browser.cjs http://localhost:8000/
node tests/block-touch.cjs http://localhost:8000/
node tests/hitofude-browser.cjs http://localhost:8000/
node tests/hitofude-touch.cjs http://localhost:8000/
node tests/rail-browser.cjs http://localhost:8000/
node tests/new-games-browser.cjs http://localhost:8000/
# 別サーバー不要。Gitの旧mainから一時サーバーを作って更新を検証。
node tests/home-pwa.cjs 7ba3b75
```

## GitHub Pagesで公開

このフォルダの**中身**をリポジトリのルートにアップロード。GitHubの **Settings → Pages → Deploy from a branch → main / (root) → Save** を選択します。表示されたHTTPSのURLをAndroid Chromeで開けば遊べます。リポジトリ名のサブディレクトリ配下でも動作する相対パスです。

## ホーム画面に追加・オフライン

Android Chromeで公開URLを一度開き、読み込みを待ってから、メニューの「アプリをインストール」または「ホーム画面に追加」を選びます。通常のブラウザでもインストールせず遊べます。

PWAはHTTPS（ローカルではlocalhost）で有効になります。初回キャッシュ完了後はホーム・難易度選択・7ゲームの問題自動生成をオフラインで遊べます。端末のキャッシュを消した場合は再度オンラインで開いてください。スマートフォンからPCのLAN IPへHTTP接続した場合はゲームは遊べますが、PWA・オフライン機能は有効になりません。

## 新しいゲームを追加する手順

1. `games/新しいID/` にゲーム本体を用意します。難易度選択が必要なら `difficulty.html` も用意します。
2. `assets/games/新しいID.svg` に紹介イラストを保存します。既存と同じ `viewBox="0 0 400 250"` を推奨します。
3. `home.js` の `games` 配列へ1件登録します。順番を入れ替えると表示順も変わります。HTMLやCSSのカード追加は不要です。

```js
{
  id: "new-game",
  title: "ゲームの なまえ",
  category: "ひらめきパズル",
  description: "みじかい せつめいを ここに！",
  href: "./games/new-game/difficulty.html",
  image: "./assets/games/new-game.svg"
}
```

5枚目は3行目の左、6枚目は右、7枚目以降も2列で自動配置されます。10種類以上でも縦にスクロールでき、下部の草原は一覧の後ろへ移動します。実装済みゲームだけを登録してください。

段階式10問ゲームは `games/common/ten-game.js` を利用できます。新3ゲームはこの共通処理で説明・練習・進捗・終了・一時停止を管理しています。従来の共通あそびかたを使う場合は、`app.js` の対象パスと `guides` に新ID・3ステップを登録します。オフライン対応には `service-worker.js` の `FILES` に新ゲームの実行ファイルとSVGを追加し、`VERSION` を上げてください。丸文字フォントは全かな・英数字を含み、未収録の漢字などは端末のフォントで表示します。

## 確認状況

2026-10-11、main `7ba3b75` を基に3ゲームを追加しました。既存4ゲームの本体、共通CSS、従来のあそびかた、manifestは変更していません。2列のホームデザインは維持し、ゲーム一覧は7件です。

既存4ゲームも両難易度の起動・説明・リセット・10問終了・再挑戦を回帰確認しました。PWAは実際のv14からv15へ更新し、78ファイルの保存・旧キャッシュ削除・他アプリのキャッシュ保持と、サブディレクトリで7ゲームのオフライン操作を確認しています。
