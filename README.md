# わくわくミニゲーム

スマートフォン向けの子ども用ゲーム集。ホームの大きなカードから「ピカッとひとふで」を選び、「かんたん」「むずかしい」を選択して遊びます。電池からドラッグして、通行可能なすべてのマスを一度ずつ通るとクリア。電池以外の通行可能マスはすべて電球で、通ると点灯します。障害物・再訪・斜めは禁止。指を離しても線の先端から再開できます。

問題は毎回自動生成します。リセットは同じ問題を最初からやり直し、クリア後の「つぎへ」は同じ難易度の新しい問題を生成します。固定10問の上限はありません。ゲームを開き直すと新しい問題から始まります。

- かんたん: 3×3または4×4、障害物1～3マス。角から始まり、直進を優先した短めの経路です。
- むずかしい: 5×5、障害物3～6マス。盤面の内側からの開始を基本に、分岐のある形を作ります。

先に重複のない上下左右の経路を作り、その外側を障害物にします。生成後に経路・電球・障害物の整合性を検証します。試行回数に上限を設け、経路が作れない場合も解ける折り返し経路に切り替えます。

HTML / CSS / JavaScriptのみ。npm・Node.js・ビルド・外部素材・CDN・バックエンドは不要です。

## ファイル構成

```text
index.html / style.css / app.js    ホーム・共通PWA登録
games/hitofude/
  difficulty.html                 難易度選択
  index.html / style.css / game.js  ゲーム画面・操作
  stages.js                       問題の生成・検証
icons/icon-192.png / icon-512.png  オリジナルアイコン
manifest.json / service-worker.js PWA・オフラインキャッシュ
index (2).html / tests.js         ブラウザ用ロジックテスト
TEST_REPORT.md                   現在の検証記録
```

## ローカル起動

ZIPを展開し、`index.html`があるフォルダで:

```sh
python3 -m http.server 8000
```

PCで `http://localhost:8000/` を開きます。`http://localhost:8000/index%20%282%29.html` で12項目の検証（両難易度の各5000問、合計10000問を含む）を実行できます。Pythonは確認用サーバーだけに使います。

## GitHub Pagesで公開

このフォルダの**中身**をリポジトリのルートにアップロード。GitHubの **Settings → Pages → Deploy from a branch → main / (root) → Save** を選択します。表示されたHTTPSのURLをAndroid Chromeで開けば遊べます。リポジトリ名のサブディレクトリ配下でも動作する相対パスです。

## ホーム画面に追加・オフライン

Android Chromeで公開URLを一度開き、読み込みを待ってから、メニューの「アプリをインストール」または「ホーム画面に追加」を選びます。通常のブラウザでもインストールせず遊べます。

PWAはHTTPS（ローカルではlocalhost）で有効になります。初回キャッシュ完了後はホーム・難易度選択・問題の自動生成をオフラインで遊べます。端末のキャッシュを消した場合は再度オンラインで開いてください。スマートフォンからPCのLAN IPへHTTP接続した場合はゲームは遊べますが、PWA・オフライン機能は有効になりません。

新しいゲームは `games/ゲーム名/` とホームのカードを追加し、`service-worker.js`の`FILES`にも必要なファイルを追加します。公開ファイルを変更するときは同ファイルの`VERSION`を更新します。

## 確認状況

自動テスト12項目と生成問題10000問の検証が成功しています。Chromiumでホーム→難易度選択→ゲーム、両難易度のドラッグ・タッチ入力のエミュレーション、リセット、次の問題、PWA更新、オフライン動作を確認しました。物理端末のタッチとPWAインストールは未確認です。詳細は [TEST_REPORT.md](TEST_REPORT.md) を参照してください。
